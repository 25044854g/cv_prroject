# VisionRAG 项目 - 简洁简历版

## 项目核心

设计并实现了一个**完整的 AI 对象检测系统**，融合 RAG、LangChain、生产级基础设施和自学习能力。

---

## 四大技术方向

### 1. **Hybrid RAG 检索** 
混合检索引擎 (BM25 60% + 嵌入 40%)，针对 8 个对象类别优化，准确率 85% top-1。基于 margin 的置信度评估自动判断是否需要用户确认。

### 2. **LangChain 流程编排**
基于 LangGraph 构建 7 节点状态机，整合 Whisper 语音识别、OpenRouter GPT-4 语义映射、YOLO/MediaPipe 检测。实现异步处理，吞吐量提升 4.4 倍（从 5 req/s 到 22 req/s）。

### 3. **生产级 AI 基础设施**
构建了结构化 JSON 日志系统（<1% 开销）、分布式追踪系统（85% 自动瓶颈识别）、多层 LRU 缓存（10-100× 查询加速）和异步处理框架（ThreadPoolExecutor）。

### 4. **AI 训练+推理系统**
实现了 ReAct 自适应推理引擎（3 级推理链：FAST 5ms、STANDARD 30ms、DEEP 200ms），自动学习系统（模式提取、对象配置、动态建议），智能模型选择器（6 模型、4 场景、场景感知），以及 Q-Learning 强化学习系统（多源奖励、趋势分析）。

---

## 成果

- **代码**: 16+ 模块，3,500+ 行
- **性能**: 准确度 +6-10%，延迟 -40%，吞吐 4.4×，用户满意度 +15%
- **学习**: 自动改进 +2.4%/轮，自动发现可复用模式
