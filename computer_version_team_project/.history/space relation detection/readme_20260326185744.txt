第3部分：空间关系分析
这是最关键的一步！我们要让系统判断：

手在物体的哪一边（左？右？上？下？）
手和物体的距离（近？远？）
是否可以抓取（手和物体足够接近吗？）
原理简解
回想一下：

手部检测得到的是：手指尖的坐标 (x, y)
物体检测得到的是：物体边框的坐标 (x1, y1, x2, y2)
通过比较这些坐标，我们就能判断相对位置。

比如：

Code
如果 手的x < 物体的x ：手在物体左边 → 说"向右移动"
如果 手的x > 物体的x ：手在物体右边 → 说"向左移动"
如果 手的y < 物体的y ：手在物体上面 → 说"向下移动"
如果 手的y > 物体的y ：手在物体下面 → 说"向上移动"
